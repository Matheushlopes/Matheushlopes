### Sobre mim

Programação é um hobby que nasceu da curiosidade de entender como as coisas funcionam e descobrir o que é possível criar com código.

Gosto de começar com um problema, experimentar soluções e transformar a ideia em algo que realmente funcione. Às vezes é uma automação para facilitar uma tarefa; em outras, um sistema, uma simulação ou um experimento que simplesmente despertou meu interesse.

Não me preocupo em fazer todo projeto virar algo grandioso. O processo de aprender, testar e melhorar faz parte da diversão.
